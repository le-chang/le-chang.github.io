# CV source

`Le_Chang_CV.docx` is the Word source of the public CV. The file served on the site,
`assets/pdf/Le_Chang_CV.pdf`, is exported from it.

To update the CV: edit the .docx, export it to PDF, and replace `assets/pdf/Le_Chang_CV.pdf`.
This folder is excluded from the Jekyll build (see `exclude:` in `_config.yml`), so the .docx
is version-controlled but not published on the website.
